# SoundCIT — пример пака

Рабочий ресурспак, который можно включить и сразу услышать результат, а потом править под себя.
Звуки намеренно синтетические и узнаваемые — чтобы сразу было ясно, сработала подмена или нет.

## Установка

Положите папку (или собранный `SoundCIT-Example-Pack.zip`) в `resourcepacks/` и включите пак в
настройках. Мод SoundCIT должен стоять в `mods/`.

## Что попробовать

| Предмет | Назовите его | Что услышите |
|---|---|---|
| Булава | `Frying Pan` | Звон сковородки при попадании, свист при замахе, звон при поломке |
| Любой меч | `Громовой клинок` (или что угодно со словом «гром») | Раскат грома при попадании |
| Трезубец | `Мьёльнир` или `Mjolnir` | Гром от Проводника, перезвон при возврате, звон при втыкании в землю |
| Что угодно | `Звенящий посох` | Перезвон — правило-подложка с низким приоритетом |

Переименовывать можно наковальней или командой:

```
/item modify entity @s weapon.mainhand {function:"minecraft:set_name",name:'"Frying Pan"',target:"custom_name"}
```

## Что показывает каждое правило

- **`01_frying_pan.json`** — простейший случай: точное имя и семантические триггеры.
- **`02_any_sword_named_thunder.json`** — маска `ipattern:` в имени и список предметов массивом.
- **`03_mjolnir_trident.json`** — регулярное выражение в имени и **прямая замена по id ванильного
  звука**, которая точнее семантических триггеров.
- **`04_fallback.json`** — правило без поля `item` с отрицательным `priority`: срабатывает только
  там, где не сработало ничего конкретнее.

Поле `_comment` мод игнорирует — им удобно оставлять пояснения прямо в правилах.

## Проверка

- `/soundcit list` — видно ли правила пака
- `/soundcit debug`, затем `/soundcit why` — что и каким слоем подменилось

Правки подхватываются по **F3+T**, перезапускать игру не нужно.

## Замечание про версии

`pack.mcmeta` здесь указывает `pack_format: 88` — это Minecraft 26.2. Для 1.21.1 поставьте `34`.
Полное описание формата — в [руководстве](../../docs/PACK_GUIDE.md).
