# SoundCIT

**CIT, но для звуков.** Переименуйте предмет так, чтобы имя совпало с правилом из ресурспака — и
вместо ванильных звуков он зазвучит по-вашему.

Булава по имени «Frying Pan» звенит сковородкой. Трезубец «Мьёльнир» гремит громом. Тотем с именем
«Lifeline» спасает вас под свой собственный звук.

*Sound replacement driven by item names. English guide: [docs/PACK_GUIDE.en.md](docs/PACK_GUIDE.en.md)*

---

## Установка

Minecraft **26.2** (ветка `port/26.2`) или **1.21.1** (ветка `main`), NeoForge. Положите jar в
`mods/`. На сервере мод **не обязателен** — вся логика клиентская.

## Быстрый пример

`assets/mypack/soundcit/frying_pan.json` в любом активном ресурспаке:

```json
{
  "item": "minecraft:mace",
  "pattern": "Frying Pan",
  "sounds": {
    "hit": "mypack:frying_pan_hit",
    "attack": "mypack:frying_pan_swing"
  }
}
```

Звуки — обычные `sounds.json` и `.ogg` в том же паке. Правки подхватываются по **F3+T**.

Заменять можно 45 категорий звуков: ближний бой, добыча, стрельба, трезубец во всех фазах, тотем,
щит, стадии зарядки арбалета, рыбалка, элитры, поломка предметов, вёдра, инструменты по блокам,
станки. Полный список — в [руководстве](docs/PACK_GUIDE.md#полный-список-триггеров).

## Как это устроено

Подмена происходит в одной точке — там, где клиент отдаёт звук движку. Сложность в другом: понять,
каким предметом звук вызван, ведь сервер присылает лишь «сыграй такой-то звук в такой-то точке».
Мод опрашивает четыре независимых источника по убыванию достоверности и берёт первого, для которого
правило действительно нашлось: подсказку сервера, сущность-источник звука, предсказанное действие
клиента и поиск подходящей сущности рядом.

Если однозначно определить предмет нельзя, мод намеренно **не** подменяет звук: украсть чужой хуже,
чем пропустить свой.

## Мод на сервере (необязательно)

Ставить на сервер не нужно, но если поставить — догадки заменяются фактами: сервер сообщает, какой
предмет вызвал звук. Правила при этом остаются личным делом клиента, сервер их не видит, у разных
игроков могут быть разные паки. Совместимость не ломается ни в одну сторону.

## Команды

- `/soundcit list` — загруженные правила
- `/soundcit debug` — подробный лог, включая причины отказа
- `/soundcit why` — последние подмены с указанием, чем определён предмет

## Сборка

```
./gradlew build          # jar в build/libs/
./gradlew runClient      # dev-клиент
./gradlew runTestClient  # headless-автотест
```

Для 26.2 нужна Java 25, для 1.21.1 — Java 21.
