# SoundCIT для Paper

Серверная половина мода. Ставить **не обязательно** — мод работает и на ванильном сервере, — но с
ней догадки заменяются фактами: сервер сообщает клиенту, какой предмет вызвал звук.

## Зачем

Клиент видит далеко не всё. Чужой тотем срабатывает и исчезает из рук раньше, чем клиент узнаёт о
событии; блок щитом другого игрока клиент не предсказывает вовсе. Плагин закрывает именно эти
случаи.

Правила при этом остаются **личным делом игрока**: сервер их не видит и не раздаёт, у каждого может
быть свой ресурспак.

## Установка

Положите `soundcit-paper-*.jar` в `plugins/`. Paper 26.2, Java 25.

Игроки без мода ничего не заметят: сообщения на незарегистрированный канал платформа молча
отбрасывает.

## Как это устроено

Естественным ключом для сопоставления был бы `seed` звука, но Bukkit его для ванильных звуков не
отдаёт — это давняя незакрытая просьба к Paper, а читать его пришлось бы перехватом пакетов через
ProtocolLib. Поэтому подсказка привязана не к конкретному звуку, а к паре «сущность + действие»:
клиент кладёт её в тот же трекер, где живут его собственные предсказания. Перехват пакетов не нужен.

Отправляются только предметы **с кастомным именем** — единственное, что сейчас проверяют правила, —
так что в обычной игре трафик практически нулевой.

## Совместимость канала

Вопрос был неочевидный: мод регистрирует канал средствами NeoForge, а плагин пишет байты вручную —
примет ли клиент такое сообщение от сервера, с которым не было рукопожатия NeoForge?

По исходникам NeoForge — примет. Входящие payload ищутся по одному лишь идентификатору канала среди
зарегистрированных, и отсутствие согласования не мешает: проверяется только наличие регистрации и
направление передачи. То есть сообщение от Paper-сервера попадает в кодек мода.

Порядок байтов обязан совпадать с кодеком: сначала байт вида, затем ключ, затем три строки с
префиксом длины. Расхождение здесь не даёт ошибки — просто получается мусор, — поэтому кодировщик
плагина и кодек мода нужно менять только вместе.

**Это вывод из чтения исходников, а не результат запуска.** Связка «плагин → клиент» вживую пока не
проверена: машина, на которой велась разработка, не тянет Paper-сервер и клиент одновременно —
клиент отваливается по таймауту раньше, чем доходит до проверки. Ошибок канала при этом в логах нет
ни с одной стороны. Проверить можно так:

```
./gradlew runTestClient -PsoundcitServer=адрес:порт
```

Автотест зайдёт на сервер, выдаст себе предмет с именем, кликнет им и проверит флаг
`ServerHintStore.isServerAssisted` — он выставляется только если payload дошёл и разобрался.
